# 窗口辅助接待候选

直接打开 **WeChat Guided Preview** 会进入隔离演练。确认演练窗口，选择「开始监看」，待办出现后可暂停监看、选草稿、点击「核对并发送」。演练会模拟发送与读回；不打开微信，也不会联系任何真实好友。关闭预览只结束它自己启动的服务。

在已经约定一个**同意参加测试的专用好友**、且可以核对真实发送的情况下，可选用实际窗口试点。运行独立包中的可执行文件，按如下参数调用（从该独立包的实际路径启动）：

```sh
<独立包>/Contents/MacOS/workbench-preview --live-test '专用好友的精确会话标题' '试用期限：试用期是七天。'
```

两项参数分别是本轮唯一允许的会话标题和用来检索的测试知识。传入的是测试数据；不要传隐私或真实业务资料。每次真微信试点创建新的独立资料目录。知识库、待办和运行记录均与正式 WeChat Bot 分开，候选不连接 Bot Studio 或外部模型。测试结束后仍可在独立资料目录核对记录。

在微信中手动打开测试会话；在工作台选择、确认该微信窗口后才开始读。系统缺少屏幕录制权限时只能查看窗口状态；实际发送还需要辅助功能和事件发送权限。应用不会代开微信、改变系统授权或自动切会话。当前版本只读取选中会话的可见来信，不保证补齐滚出视口的历史；真微信发送只支持一个可识别微信窗口。若窗口消失、会话切换或读图失败，先停下，不改绑。

待办采纳后还需单独核对完整正文和收件人。现有人工操作停避可能等待至多 90 秒；提交后请等待回执，关闭窗口不能撤回已经发出的消息。仅在同一窗口再次读回新增且匹配的出站气泡时记为本机已核验；不能据此判断对方已收到或已读。结果不清楚时查看微信，不自动重试。
